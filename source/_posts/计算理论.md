### lecture2

2. DFA 的五个部分：(Q \Sigma \delta s F)(Formal definition of DFA)

- **有限**的 state
- 明确的输入字符集

w = w_1 w_2 ... w_n, M accepts w 的话，说明存在 r = r_0 r_1 ... r_n 使得：

- r_0 = s
- \delta(r_i, w_{i + 1}) = r_{i + 1}
- r_n \in F

### lecture4

1. 给出了正则表达式的概念：

- 字母表 \Sigma 中的单独一个字符
- 空串
- 空集
- 两个正则表达式的并、连接、* 运算

2. L(R), or R denotes the language described by regular expression R. 这个意思是，正则表达式可以用来描述一个正则语言。这个意思是，正则表达式的语言我们经常使用 L 来描述，或者直接使用 R 这个表达式代表这个语言。

- L(a) = {a}
- L(\epsilon) = {\epsilon}
- L(\phi) = {\phi}
- 并、连接、* 的 L 就是 L 的并、连接、*

3. A language is regular if and only if some regular expression describes it. 一个语言是正则的，当且仅当存在一个正则表达式描述这个语言。

要证明两个方向，详细的证明见 lecture4 课件。其中，证明正则语言可以用正则表达式描述的时候，我们定义了 GNFA，是一种扩展了的 NFA，允许每个转换标记上可能包含一个正则表达式，而不仅仅是单个字符或空字符（ε）。

也就是说，在普通的 NFA 中，我们只能通过单个字符进行状态转换，但是在 GNFA 中，我们可以通过任意的正则表达式来转换。

结构：GNFA有一个特定的起始状态，该状态没有任何进入的转换（只有出去的转换），和一个特定的接受状态，该状态没有任何出去的转换（只有进入的转换）。（也就是说，起点只有出边，终点只有入边，且仅一个初始状态与一个结束状态）

4. the formal definition of GNFA 也是一个五元组，但是转移函数不同，为 Q - q_accept \times Q - q_start -> R，其中，R 是一个正则表达式。

the formal definition of computation 使用 w 和 q 来描述接受，并且也是 3 个条件

3. 引入了泵引理 pumping lemma 来证明一个语言不是正则的，因为所有的正则语言都满足泵引理，所以如果一个语言不满足泵引理，那么这个语言就不是正则的。

注意泵引理的几个关键点：如果 A 是一个正则语言，那么一定存在一个泵长度 p，对于 A 中任意一个长度大于等于 p 的字符串 s，s 可以分为 xyz 三个部分，且满足：

- for each i >= 0, xy^{i}z \in A
- |y| > 0
- |xy| <= p
 
感性理解就是，y 不能太靠后，并且 x 和 z 可以是空串，但是 y 不能是空串。

### lecture6

1. 上下文无关语言 context-free language 简写 CFL 严格大于正则语言，由上下文无关文法 context-free grammar 简写 CFG 生成，这种文法比正则文法更加强大，可以描述更加复杂的语言形式。

2. CFGs context-free grammers

一个文法由一组替换规则组成（一个对一组），替换规则又称为产生式。

每条规则占一行，由一个符号和一个字符串构成。符号称为变元，字符串由变元和另一种称为终结符(terminal)的符号组成，变元常用大写字母表示，终结符类似于输入字符，常用小写字母、数字或特殊符号表示。一个变元被指定为起始变元(start variable)，通常它出现在第一条规则的左边

3. the formal definition of CFG 一个上下文无关文法 G 是一个四元组 (V, T, R, S) 并且 V 交 T 是一个空集。

- V 是**有限**符号集合，叫做 variable 变量
- T 是**有限**符号集合，叫做 terminal 终结符
- R 是一个有限子集，是 V \times (V or T)* 的子集
- S \in V 是起始变量

一个 CFG 生成的语言：L(G) = { w∈T* | S *=> w }.

4. A language L is called context-free if there is a CFG G with L(G) = L 一个上下文无关语言是一个上下文无关文法生成的语言

5. CFL 上下文无关语言在并、交和*运算下是封闭的，课件中有三种运算各自的文法的构造方案。

6. 乔姆斯基范式 Chomsky Normal Form, CNF

A CFG is called in CNF if every rule is of the form：

- A -> a
- A -> BC, B \neq S and C \neq S
- S -> \epsilon

Each context-free language is generated by a CNF grammar. ？？？

意思是，任何一个规则，要么是两个非终结符的组合，要么是单个终结符，并且起始变量可以生成空串，且其实变量只能在左侧。

7. epsilon 并不是一个终结符，而是一个特殊的符号，表示空串。
