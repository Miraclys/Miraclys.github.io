### 第四章 Value Iteration & Policy Iteration

1. value iteration 其实是有两个部分。第一步是 Policy Update，第二步是 Value Update。我们先更新策略，然后在新的策略上再去求解最优的 state value

2. policy iteration 也是有两个部分。第一个部分是 policy evaluation(PE)，第二步是 policy imoprovement(PI)。其中，plicy evaluation 其实就是我们给定一个策略，然后求解这一个策略对应的贝尔曼公式，得到所对应的 state value。

3. truncated policy iteration 截断策略方法，是一种统一的算法

4. the value iteration algorithm is exactly the alogorithm suggested by the contraction mapping theorem for solving the Bellman optimality equation.

5. truncated policy iteration is a general algorithm that includes both value iteration and policy iteration as special cases.

6. 对于 value iteration，初始得到的是一个 v_0，然后根据这一个 v_ 0 找出最大 action value 来更新策略，然后再根据新的策略来更新 state value。这样一直迭代下去，直到收敛。对于 policy iteration，我们初始得到的是一个策略 \pi_0，然后求解这一个策略对应的 state value（求解 bellman equation），然后再根据这一个 state value 寻找最大的 action value 来更新策略。这样一直迭代下去，直到收敛。

7. 在使用 policy iteration 的时候，其实是无穷多次的迭代来求解 bellman equation，求解完以后再找 max，但是对于 value iteration 本质上只是求解 bellman equation 中迭代一次，然后就开始找 max。truncated policy iteration 是 policy iteration 和 value iteration 的结合，我们可以通过设置一个截断次数来控制迭代次数。

8. 我们的 iteration 次数增加，就是越接近 policy iteration，虽然这样的求解次数比较少，但是我们的计算量比较大。但是如果我们的 iteration 次数减少，就是越接近 value iteration，虽然这样的计算量比较小，但是我们的求解次数比较多。所以，选择一个不是很大也不是很小的 iteration 来迭代，这样既不会很慢也不会需要的求解次数过多。

8. MC exploring starts。为什么我们需要考虑每一个 starts 也就是让每一个 (s, a) pair 作为 start？虽然我们的一个 episode 中可能会包含多个 (s, a) pair，但是我们无法确定是否都会被包含。我们必须保证遍历过所有的 (s, a) pair 才可以保证找到 optimal solution。所以最笨的方法就是，每一个 (s, a) pair 作为一个 episode 开始。这样我们就能保证每一个 pair 都会出现了。后面我们会尝试优化这一个问题。（比如说，我必须获得很多从每一个 pair 对开始的 episode，实际中我们的网格世界的话，一个机器人遍历网格，对于不同的 pair 作为 episode 的开始，我们必须人为搬运机器人从一个地方到另一个地方，这就可以看作是一种开销，所以我们尝试优化）

9. 我们可以使用 sofe policies 来优化掉上面的问题。

10. epsilon-greedy 可以调节我们对于 action 的选择，是一种 exploitation 和 exploration 之间的平衡

11. 通过使用 epsilon-greedy，我们其实就不需要 exploring starts 这一个约束了。

12. epsilone-greedy 有一定的探索性。但是它的最优性被牺牲掉了。实际中，可以去平衡这两个方面。也可以让 epsilon 逐渐减小

### 第七章 Temporal Difference Learning

1. Temporal Difference Learning 简称 TD Learning，这也是一种 model-free 的方法。

2. 这是一种 incremental 的算法

3. TD 算法使用用来求解一个给定的 policy 的 state value

4. TD 算法是基于数据的，而不是基于模型的

5. TD 算法是在没有模型的情况下来求解 Bellman equation

6. TD learning can be viewed as a special stochastic algorithms for solving the Bellman or Bellman optimality equations.

7. TD learning 相对于 MC 方法的优势是，它是一种 incremental 的形式。

8. 这一章的一些算法的总体关系：
   
the most basci TD algorithm can estimate the state values of a given policy

Sarsa can estimate the action values of a given policy. It can be combined with a policy improvement step to find optimal policies.

n-step Sarsa will show Sarsa and MC learning are two special cases of n-step Sarsa

Q-learning is one of the most classic reinforcement learning algorithms. It can estimate the optimal action values and find the optimal policy.

9. TD error 不仅仅反应了 time step 意义下的误差，也反映了当前的 state value 和最终的 state value 之间的误差

10. 对于最基础的 TD learning，我们得到的是 state value，要是想更新策略，我们需要得到 action value，但是如果是从 state value 推导得到 action value，我们需要 System model，这就和我们 model-free 的前提冲突了。所以我们需要使用 Sarsa 算法

11. Sarsa 也是一种 stochastic approximation algorithm 对于解决 Bellman Equation

12. Sarsa 也是只可以 estimate，必须 combined with a policy improvement step to find optimal policies

但是 Q-learning 可以直接 estimate optimal action values and find optimal policies

当 behavior policy 和 target policy 一样的时候，我们就是 on-policy 的方法；当 behavior policy 和 target policy 不一样的时候，我们就是 off-policy 的方法

6. 还有一个技巧是 experience replay，也就是我们不是每一次迭代都使用最新的 experience，而是从之前的 experience buffer 中随机抽取一些来进行学习。
