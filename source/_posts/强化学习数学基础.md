### 第二章 Bellman Equation

1. the state value can be used to evaluate policies. 

2. we need to calculate the state value of a policy from Bellman equation, so that we can compare different policies. 

3. 关于求解 Bellman Equation，课本中给出了两种方式。第一种是求解逆矩阵，但是不太好求。所以我们第二种方式是一种迭代的方式来求解，不需要求逆矩阵。

4. action value 是指的 「在一个状态下采取某一个行为的」（一定要有在一个状态下） 期望

5. As we will see later in this book, action values play a more direct role than state values when we attempt to find optimal policies

6. Bellman Equation 不仅仅在强化学习领域应用，在运筹学、控制论等领域都有应用

7. 不同领域的 Bellman Equation 形式不同，本书的形式是建立在 discrete Markov decision processes 下面的。
